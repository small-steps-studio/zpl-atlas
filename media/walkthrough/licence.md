# Licence and help

* **Buy Pro** opens the checkout of the payment provider (Personal USD 19, Business USD 39 per user).
* **Enter Licence Key** unlocks Pro on this computer; a key works on up to 3 computers.
* **Show Licence Status** shows the licence or the days left in the trial.
* **Report A Problem** copies a diagnostics block without any file contents and opens the issues page.
